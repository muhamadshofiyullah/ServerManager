# ServerManager

**ServerManager** adalah aplikasi Windows yang dirancang untuk mempermudah operasional server pulsa dan PPOB. Aplikasi ini membantu Anda mengawasi saldo supplier secara otomatis, merekap mutasi bank dan laporan harian, menyesuaikan harga produk secara otomatis, serta mengirimkan notifikasi langsung ke bot Telegram.

---

## ✨ Fitur Utama

- 💶 **Pemantauan Saldo Supplier**: Mengecek saldo supplier secara otomatis dan berkala. Dilengkapi fitur untuk mengaktifkan atau menonaktifkan supplier tertentu serta pembuatan tiket deposit otomatis saat saldo menipis.
- 📊 **Laporan Harian (Daily Report)**: Rekapitulasi otomatis saldo bank, saldo supplier, saldo member, perkiraan modal, dan laba harian.
- 🏦 **Manajemen Mutasi Bank**: Memantau transaksi masuk/keluar, saldo awal, dan saldo akhir bank secara otomatis.
- 🏷️ **Update Harga Otomatis**: Memperbarui harga beli dan harga jual produk secara otomatis berdasarkan perubahan harga dari pihak supplier.
- 🤖 **Integrasi Bot Telegram**: Menerima perintah cek saldo melalui Telegram secara *real-time*.

---

## 🚀 Cara Penggunaan

1. **Unduh File Aplikasi**:
   Unduh file aplikasi `ServerManager.exe` dari repositori ini sesuai dengan versi yang Anda inginkan.
2. **Jalankan Aplikasi**:
   Buka dan jalankan file `ServerManager.exe` pada komputer atau server Windows Anda.
3. **Perubahan Versi (Naik / Turun Versi)**:
   Jika Anda perlu melakukan peningkatan (*upgrade*) atau memilih versi terdahulu (*downgrade*), Anda cukup mengunduh file `ServerManager.exe` dari folder riwayat versi yang tersedia di repositori ini.
